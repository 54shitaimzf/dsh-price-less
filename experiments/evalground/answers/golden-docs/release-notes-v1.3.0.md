# dsh-sample-plugin v1.3.0 发布说明

## 新特性

- link 依赖审计：现在支持 node-modules 清单核对，link 依赖的安装状态可以直接从清单确认，不必再手工对照目录。

## 修复

- 修复 semver 门错误放行：此前版本判断按字符串比较，1.10.0 会被误判为小于 1.9.0；本版本改为按数值段比较，版本门恢复正确行为。

## 兼容性

- 审计报告输出改为按严重度排序（error → warn → info），解析 JSON 的消费方字段不变；依赖清单核对为新增检查项，不影响既有规则字段。
- 未引入新的运行时依赖，link 依赖集合不变。

## 致谢

感谢参与样例包与审计器联调的维护者，以及提供产物结构反馈的插件作者们。

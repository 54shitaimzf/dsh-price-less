# 00 · 系统导览与公共契约

> 一句话定位：**`@dsh-external/dsh-context-economy` = DSH 的全自动上下文管理工具**——
> 双核心（优化判别器 / 压缩器）+ 四层防御（交换对剪切 / task 边界压缩 / 40% 压力 /
> 防溢出保险丝），围绕五条节约理念运转。
> 本文登记公共件（理念 / 配置 / 事件 / 状态 / 预算 / 度量 / 命令 / 术语 / 路线图），
> 细节一律回指域文档。状态：设计 · 未实现（搭建序见 [11 §8](11-structure.md)）。

## 0. 它解决什么问题（人话版）

把"送进模型的每个 token"当成一次付费打车：多塞一个字就多付一笔，车厢越满，越容易把真正
重要的东西挤掉。浪费很具体：一次文件读就是 10–16K token；agent 反复 grep 同一个文件、
反复重读看过的大段结果；用户问过的五个"为什么"理解完之后还躺在上下文里每轮计费；
一件事的操作路径明明固定，模型每次都重新摸索一遍；历史越滚越大，前缀缓存稍微一断
后面全白算——而且这种浪费按轮次复利。

这套件让喂给模型的内容**又少又准**，且**全自动**：判别器认 task 边界、剪切层随时清掉
成熟内容、压缩器在边界折叠归档；用户唯一的主动作是可选的星标（把散落的意图整理成一份
确定化的执行包）。怎么做——五条理念（§1）；做成什么样——系统形态（§2）。

## 1. 五条节约理念（总纲；正典 = [05 §1](05-constitution.md)）

| 理念 | 一句话 | 正典落点 |
|---|---|---|
| **缓存复用** | 缓存体制决定最优上下文策略；字节稳定 + 追加式是地基 | [06](06-cache.md) |
| **软件架构经验提取** | 从易变对话提取稳定的项目结构事实，稳定点固化、跨 task 复用 | [02](02-discriminator.md) 项目帧 / [04 §6](04-compactor.md) 边界档案 |
| **无关内容剪枝** | 已吸收的问答、已超越的读、已交付结论的过程——正确时机整块移除，只留依据 | [03](03-shear.md) + 剪除落位律 |
| **执行路线确定化** | 能提前钉死的绝不临时搜索；技能/命令显式引用 + 坐标寻址 | [02 §5](02-discriminator.md) |
| **多做·相信用户决策·必要才探索** | 多做前置功换探索消失；用户宣言/确认/编辑是最高信号；探索是例外且回填固定化 | [05 §2](05-constitution.md) 条文八 + [02](02-discriminator.md) |

## 6. 公共预算

| 预算 | 值 | 约束 |
|---|---|---|
| 热尾单池 | 10K token | 贪心停机（可少不多），装配器独占算术（[04 §2](04-compactor.md)） |
| 保留尾 | retainTokens = 10K（绝对值） | `retain < thresholdTokens` 校验强制 |
| 档案区硬上限 | 15K token（绝对值） | 超限截断最老档案条目，不合并不重压（[04 §6](04-compactor.md)） |
| 压力触发 | pressureRatio = 0.4 × 压缩域窗口 | wire 锚定计量 |
| 结论句 | 每句上限，超长截断（截断安全） | 行式裁决钳制（[02 §4](02-discriminator.md)） |
| 断面输入栈 | 卷宗 + 稳定前缀 + prompt，预算钳制 | 门控：短卷宗跳过产品层 |

## 10. 术语速查（人话版）

| 术语 | 人话解释 |
|---|---|
| **优化判别器** | 一个理解核两个断面：读 task 用户消息，判边界 + 整理执行包 |
| **断面** | 一次完整的理解调用（星标 = 手动断面；逐消息 = 自动断面） |
| **星标** | 手动断面入口：点一下，散落的意图/约束/验收/路径整理成优化后 prompt |
| **卷宗** | task 内用户消息的原文累积（判别的唯一语料，边界清空） |
| **稳定前缀** | 技能目录 + 项目最终目标，跨 task 稳定、版本化 |
| **项目帧** | 项目最终目标 + 方面分解（init 采集，用户确认） |
| **task** | 为项目某一方面目标的持续努力（意图轴单位） |
| **子task** | task 内类型不同的子任务（压缩分结构单位，缝的语义） |
| **交换对** | 问答对 / 工具对——剪切层微削单位 |
| **run** | 连续的追问链 / 验证链，对话剪切的整段单位 |
| **稳定点** | task 闭合 = 区间信息趋稳——边界压缩的时机根据 |
| **对表判别** | 校准后的自动断面：对固定意图结构做封闭式核对，机械为主 |
| **断裂成本** | 变更点之后全部体积 × 全价——动历史字节的价格公式 |
| **热尾** | 边界装配保留下来的任务材料原文（≤10K，缓存不是档案） |
| **检查点** | 压力路径的进行时摘要（"我在哪、现在什么为真"） |
| **保险丝** | hard-truncate 防溢出安全阀（全臂兜底，平时 no-op） |
| **压缩域窗口** | ≈ 任务峰值上下文——一切压缩触发的标定基准（不是裸模型窗口） |
| **落位律** | 剪除必须留依据：语义在场 / 盘上在场 / 否则不许剪 |
| **带外原则** | 插件内部标志不进模型视野——没有可见标志就没有误解 |
| **机械摘句** | 零 LLM 的首句/结论句规则摘录（短 run 替身） |
| **行式裁决** | 星标断面的结构化输出：一行一决策，行级容错 |
| **引用守卫** | 产物引用的技能/命令名必须查表存在——幻觉引用机械拦截 |
| **档案堆** | 逐 task 归档的只追加前缀（事实层 + 坐标层 + 类型化摘要） |
| **字节稳定** | 同版本内容逐字节一致——缓存命中的物理基础 |
| **缓存体制** | 计费结构/命中率/TTL——决定最优上下文策略的底层变量 |
| **fail-lazy** | 证据不足/出错就维持当下，绝不外溢 |
| **L0/L1/L2** | 纯代码规则 / 结构活小模型辅助 / 真模型干语义 |

## 11. 未来路线图（当前版本不做）

| 条目 | 内容 | 重启条件 |
|---|---|---|
| **知识图谱** | 结构化事实抽取：边界 = 节点/跳骨架，图谱 = 结构源、摘要为其文本投影 | 四层防御账本基线立住，且跨 task 知识复用需求实测主导 |
| **语义化读取工具** | 按语义（问题/符号相似度）选择读取内容——"细节不在上下文"的终态形态 | 边界装配 + T0-R 到顶（重读账本显示机械手段收益耗尽） |
| **管道编排** | task 内可分性预检 → 子目标并行管道 → 修改流汇回（原设计存档 docs/legacy.md §5） | 双核心账本立住，且任务集可分性实测主导 |
| **预设开发** | 系统上下文条款预设：稳定前缀进主模型系统提示词；首批条款 = 子代理最优场景（封闭查询型三件套） | 断面/剪切配对 Δ 验证后 |
| **压缩产物增强** | 提问式压缩（接手者问题集 + 答案）/ provenance 置信度（机械推导） | 边界装配产物账本立住，作为单一变量进新实验 |
| **用户编辑信号再利用** | 星标预览编辑的差异作为高信号纠正数据的再利用形态 | 攒够编辑样本量再议（v1：编辑即终稿，不揣度） |
| **模型分工执行** | 退出计划确认动作旁挂执行模型下拉——批准计划与选定执行器一步完成；**形态 = 独立姊妹插件，不内嵌本套件**（执行路由与上下文机制正交，内嵌只添 host UI 耦合面）；协同点：星标执行包是廉价执行器接手的安全依据，切换时点遵守 [06 §2](06-cache.md) 断裂成本（每计划 ≤1 次断裂） | host 计划确认面扩展槽核验通过 + 姊妹插件立项 |
| **上下文全量导出** | 请求消息表时点快照（与压力计量同源，不另建投影）+ 剪切/压缩/前缀重建操作流水 + 四实体版本清单，确定性序列化落盘；带外工件永不入模型上下文 | 度量消息列表可视化（R3+）落地后，作为其重端形态 |

## 0. 它解决什么问题（人话版）

机制越多，最怕各写各的、互相打架——尤其"模型到底该碰什么、不该碰什么"没有准绳，模型
老被拉去干本可以确定性算出来的活，白白烧 token。这篇是整套架构的"骨架 + 定位说明书"：
每样东西待在哪一层、什么单位归谁管、模型看得见什么、一个请求长什么样、一条用户输入
走完哪几步。

主线一条：**双核心 + 四层防御 + 支撑面**。两个复用核心（优化判别器 / 压缩器）承担全部
语义工作；四层防御按单位分派（交换对剪切 → task 边界压缩 → 子task 压力 → 字节保险丝）；
其余全是支撑面（宪法守卫、缓存纪律、状态版本、工程结构）。收益是清爽和便宜：
目录一清二楚，token 只花在语义核心上；代价是守规矩——宁可"笨但确定"，不让模型去赌。

## 1. 系统形态

```
dsh-price-less —— 全自动上下文管理工具
 ├─ 核心一 优化判别器（02）：一个理解核、两个断面（星标手动 / 自动对表）
 │    产：优化后 prompt · 判别回填 · task 边界 · 剪切清单 · 度量
 ├─ 核心二 压缩器（04）：层 2 边界装配+热尾 · 层 3 压力路径(40%) · 层 4 保险丝
 ├─ 叠加层 剪切层（03）：工具剪切四档 + 对话 run 剪切（交换对微削，第一层防御）
 └─ 支撑面：宪法与守卫（05）· 缓存纪律（06）· 度量账本（07）· 实验协议（08）
          · 状态与版本（09）· 挂点接线（10）· 工程结构（11）
```

- 双核心**复用**关系：判别器产边界信号 → 压缩器消费；压缩器在边界事务中为剪切层搭车
  （T-boundary 唯一合法去处）；两核心共享事务原语（[04 §1](04-compactor.md)）与卷宗标注。
- 默认姿态**全自动**：判别、剪切、压缩自转，无人值守；星标是手动升级通道（权威整理 +
  产品），不是必需操作（宪法条文八）。
- 节约理念五条（缓存复用 / 架构经验提取 / 无关剪枝 / 路线确定化 / 多做·相信用户决策）
  正典见 [05 §1](05-constitution.md)。

## 2. 三个平面（实现约束梯度）

| 平面 | 能力 | 成本 | 负责 |
|---|---|---|---|
| L0 确定性 | 分支、查表、字符串/哈希、事件观测 | ≈0 | 纯代码 |
| L1 结构 | 差分标注、模板选择、机械摘录（模型打辅助） | 低 | 代码 + 极小模型 |
| L2 模型最小断面 | 语义核心：判别、断面整理、压缩摘要、结论提取 | 主模型 | 被调用的大模型 |

这就是"能确定的绝不麻烦模型"：L0 零成本，L1 低成本，L2 只留给"必须拿语义判断"的核心
（[05](05-constitution.md) 回退链六级是它的执行形态）。每个机制的 L0/L2 分界逐件审计——
优化判别器的审计表见 [02 §4](02-discriminator.md)。

## 3. 状态分层

| 层 | 内容 | 生命周期 | 管理 |
|---|---|---|---|
| 会话 | 对话历史、工具结果 | task 内若干轮 | 剪切层（微削）+ 压缩器（折叠） |
| task | 卷宗（用户消息 + 标注）、段状态机、优化产物 | task | 优化判别器（[09 §2](09-state.md)） |
| 项目 | 项目帧（最终目标 + 技能目录）、边界档案堆 | 项目 | init / 星标 / 压缩器（[09 §2](09-state.md)） |

三层对应三个版本的持久实体（[09](09-state.md) 统一版本协议）；会话事实全部 log-only
可回放，KV 只是加速缓存。

## 3.5 分划单位（task / 子task / 交换对 · 正典定义）

> **正典**：本节是分划单位的单一事实源，[02](02-discriminator.md)（判别）、[03](03-shear.md)
> （剪切）、[04](04-compactor.md)（压缩）均引用此处、不重复定义。三条分划轴互不相同：
> **意图轴**（task）、**活动类型轴**（子task）、**交换粒度**（交换对）——判别器只守意图轴，
> 剪切层只动交换对，压缩分结构只按子task。

**task（意图轴单位）**：为了项目**某一个方面的目标**进行的持续努力。成立证据三合一：

- **意图归属**——服务于项目目标的哪个方面（判别参照系 = 项目帧的方面分解，
  [02 §2](02-discriminator.md)）；
- **持续性强**——streak 证据，单条消息的漂移不构成边界（纯理解侧问是交换级事件，归剪切层）；
- **改动范围较固定**——足迹证据；探索型 task 足迹宽 → 范围证据弃权、意图证据主导
  （证据非法律）。

**task 的结构性特点（压缩时机的根据）**：task 可能对**上下文中项目结构的局部信息**产生
较大影响——对该局部的读、写、修订、否弃都发生在 task 内部；task 进行中，上下文里的结构
画像持续变动（T0 超越规则的另一面：写即新真相，每次写都在作废上下文里此前的读）。
**task 闭合 = 该区间信息趋于稳定的稳定点**——这正是**在 task 边界压缩**的根本原因：

- 压缩产物是**事实层 + 坐标层**双层。事实层（做了什么 / 结论是什么 / 否弃了什么）必须在
  稳定点冻结才有效——中途折叠写下的是"当前正在做 X"，会被后续动作推翻，产物从写出即错
  （且比原始历史更危险：摘要形态自带信任）。坐标层（文件随后续 task 修改而漂移）由版本
  机制机械吸收（快照补丁链 vN 重映射，[04 §2](04-compactor.md) 双通道），**不需要也不允许
  靠重压修正**——重写已稳定字节即破坏 append-only / 不可重压律（[04 §3](04-compactor.md)
  机制 A 的深层根据）。稳定 ≠ 永久：后续 task 改同一文件，不推翻已闭合 task 的历史事实，
  只产生坐标漂移。
- 与剪切时机经济学（[06 §2](06-cache.md) 断裂成本公式）互补：公式定价**折叠动作**；本条
  定价**折叠内容的效度**。边界压缩 = 在"内容已稳定"与"新 task 材料即将接管上下文"的
  交点上做一次性大折叠。
- 压力路径形态由此解释：中途**没有稳定点** → 压力产物只能是进行时检查点（明示"我在哪、
  现在什么为真"，不宣称最终事实）+ 不可重压续传。

**子task（活动类型轴单位）**：task 内部**类型**不同的子任务（构建 / 审查 / 测试 / 调试…），
是压缩的**分结构单位**（不同 type 不同压缩结构），由 **task 总目标统领**（折叠分块引用
总目标保持连贯，无需各自重建语境）。子task **不预先注册、无检测机制、无档案地位**——
只存在于压缩产物内部。[04 §3](04-compactor.md) 的"缝"据此有语义标准：缝 = 相位边界的
识别，**好缝落在类型转换边界**（压缩器的语义职责），机械校验仍仅单元存在 + 工具对平衡。

**交换对（剪切层单位）**：问答对 / 工具对——既非 task 也非子task 的微削单位（第一层防御）。
连续的同类交换构成 **run**（[03 §3](03-shear.md) 剪除单位）。

**四层防御 × 分划单位**（每层各得其所、互不越权）：

| 层 | 单位 | 机制 |
|---|---|---|
| 第 1 层 剪切 | 交换对 / run | 工具剪切器 + 对话剪切器（[03](03-shear.md)） |
| 第 2 层 边界压缩 | task | 类型化摘要 + 热尾原文保留（[04 §2](04-compactor.md)） |
| 第 3 层 压力压缩 | 子task | 进行时检查点 + 末段子任务全量（[04 §3](04-compactor.md)） |
| 第 4 层 保险丝 | 字节 | hard-truncate 防溢出安全阀（[04 §4](04-compactor.md)） |

## 4. 可见性

```
可见（会话内容，用户可审可改）
  [优化后 prompt（用户预览确认后直接发送）]   ← 优化判别器产出
  [用户指令原文（权威段，逐字保留）]           ← 永远最后一条
  [剪切/压缩的结论句与档案]                    ← 落位律产物（语义在场）
不可见（机制层，永不进模型视野）
  [卷宗标注、run 标志、裁决记录]               ← 插件状态（带外原则）
  [技能目录、项目帧版本]                        ← 稳定前缀的原料，经断面进入产品
```

边界规则：**无隐藏注入段**——一切给模型的知识只从可见出口进入（优化后 prompt / 结论句 /
档案堆）；插件内部标志（run 范围、行式裁决）对主模型全程不可见（[03 §3](03-shear.md)
带外原则）；权威段在任何产物中逐字可寻（守卫断言）。

## 5. 请求布局契约

```
[system + tools] [档案堆 vN] [稳定前缀内容(经产品)] [实例/热尾] [用户指令] → 生成
     稳定            只追加       按版本 bump            动态        最后一条
```

"稳定在前、动态在后"（[06 §3](06-cache.md) 三铁律）；档案堆只追加，越界按 15K 硬帽截断最老条目（[04 §6](04-compactor.md)）；
用户指令恒最后（最高近因）。

## 6. 决策链（一次用户输入）

```
用户输入
  → 自动断面：T0/L0/L1 对表（命中即返回）→ 歧义才 LLM 判定（三分类搭车）
  → 动作到达 → 对话剪切器冲刷理解/验证 run（机械）
  → 主模型执行（优化后 prompt 的固定化路线；探索为例外）
  → task 闭合（边界信号）→ 压缩器边界装配（事实层冻结 + 热尾）→ 档案归档 vN
  → （任意时刻）星标 → 手动断面 → 优化后 prompt + 回填 + 剪切清单
```

## 8. 验收标准

- [ ] 平面归属清晰：能归 L0/L1 的没有偷渡到 L2（各机制审计表对账）；
- [ ] 分划单位不越权：剪切只动交换对/run、边界压缩只动 task、压力只按子task、保险丝只按字节；
- [ ] 可见性：权威段在任何产物中逐字可寻；插件内部标志零进模型视野（回放断言）；
- [ ] 关闭任一层（剪切/边界/压力），其余功能完整；
- [ ] 同版本各持久实体逐字节一致（哈希 CI）。

# 05 · 规则域：确定性宪法与守卫

> 域定位：**规则域给全部机制提供判定原则与审查口径**——条文与回退链在本篇（文档权威），
> 运行时由主插件内建守卫执行（[docs/12 §4](12-main-plugin.md)）。

## 0. 它解决什么问题（人话版）

这个域自己不干活，它给所有机制当"裁判 + 尺子"。痛点很现实：各域自己判断，就容易越界——该用规则就算出来的，请了模型去算；能查表的版本号，重算了一遍；最要命的是失败时没有兜底，直接崩。token 就是这么一点一点被烧掉的。

思路是定一套**判定标准**：七条宪法条文（每题一句话，告诉你怎么判断该不该让模型碰）+ 一条**回退链**（从最便宜到最贵，逐级尝试、不跳层）+ 一份**审查清单**（模块合并前逐项自证）+ 一个**合规自证模板**（写进模块注释）。任何一个模块要合进来，先自证"我够便宜、够确定、够可复现"。

收益是 token 花在刀口上、失败永远有退路、可复现（同输入同输出）。代价是每条都要写证据、要对得上账本，宁严勿松——因为这里松一寸，后面烧的就是真金白银。

## 1. 宪法条文（判定原则）

1. **确定优先**：可观测的用日志事件，可计算的用规则，可查表的用版本号；
2. **模型最小断面**：进入模型的每个 token 满足两个条件——非可确定计算；缺失会导致猜错；（也就是"这块内容不是靠规则能算出来的，而且不给模型它会猜错"才值得花这个 token）
3. **字节可复现**：同输入 → 同输出；LLM 产物的复用先版本化落盘；（**字节可复现**就是**字节稳定**：同版本内容逐字节一致，这是缓存命中的物理基础）
4. **成本可见**：任何进入请求的 token 都有预算与度量；
5. **降级显式**：确定性检索失败走明确降级路径（`off` 档、机械等价、占位+用户可控指令）；（**降级/退化** = 某个能力没触发时，用更笨但确定的方法兜底，全系统照样能跑）
6. **自包含有效性**：模型可见的工具结果必须是"内容即所得"的实际文本——需要模型解引用/重建/跨距离关联的机制无效；（**自包含** = 模型拿到的就是成品文本，不用再去查别的工具/文件才能用）
7. **度量先行**：改动必须可被 [docs/07](07-metrics.md) 观测。

## 2. 回退链（逐级尝试，成本递增）

```
1. 用户可控指令（用户显式规则直接采用）
2. 代码分支（gating / 任务类型 / 模板命中 / 阈值判定）
3. 机械字符匹配（关键词、模式、正则、哈希、字符串签名）
4. 本地 embedding（相似度检索，离线、无 API 费）
5. 极小本地模型（差分标注、锚定片段合成；输出可版本化、预算受限）
6. 被调用的大模型（最小断面：工作摘要 / 压缩摘要 / 语义化标注）
```

> **回退链** = 一条从最便宜到最贵的手段序列，各域共享、绝不跳层。第 1 级是**用户可控指令**（用户显式规则直接采用），纯零成本；第 2 级**代码分支**（gating / 任务类型 / 模板命中 / 阈值判定）是写死在代码里的判断；第 3 级**机械字符匹配**（关键词、模式、正则、哈希、字符串签名）；第 4 级**本地 embedding**（本地向量检索，离线、无 API 费）；第 5 级**极小本地模型**（差分标注、锚定片段合成，输出可版本化、预算受限）；第 6 级**被调用的大模型**（最小断面：工作摘要 / 压缩摘要 / 语义化标注），最贵。
> 每个模块自证"步数最小"：第 2 步可解的不到第 5 步——能用便宜的解决，绝不走贵的。

## 3. embedding（v0.2.0-s6 状态：端口空壳，off 档零成本）

- 本插件**不再携带** embedding 模型/vendor 运行时（`files` 已去除 models/、vendor/，约省 198MB）；
- 边界语义票（v0.2.0-s6 移除）与机械判定层（v0.3.0 退役）均已不再用于判界——**判界 = 判别器
  （语义判定，v0.4.0 接入）：L0 快路径 + L1 缓存 + LLM 主路径 + fail-lazy 兜底**（docs/03 §1、
  src/discriminator/*；回退链步数：T0 显式 → 2(L0 词表) → 3(L1 缓存) → 4(LLM 判别 = 主路径)）；
  `EmbeddingPort`（[docs/11](11-embedding.md)）仅保留为**端口接口空壳**（src/task/embedding.ts），
  供「映射检索」域（docs/15，蓝图）将来接入 embedding 实现时使用；
- 映射检索届时若接入 embedding，仍遵循"机械优先、embedding 只在低置信窗口触发"的降级矩阵：

| 用到 embedding 的机制 | 降级为 | 影响 |
|---|---|---|
| 判别器语义票（输入域，已落地） | 失败回退 continue（fail-lazy，docs/03 §1 第 5 步） | 边界判定保守（宁漏不错） |
| 映射/意图检索（锚定，提示词域，蓝图） | 机械关键词 + Jaccard + symbol 查表 | 小项目无损；大库召回略降 |
| 修补识别弱票（压缩域，蓝图） | 无弱票 → 两个强证据 | 修补识别更保守 |

## 4. 运行时守卫（执行表见主插件）

四检查器（预算/字节/补丁/回退链）的判定与拦截语义**唯一**以 [docs/12 §4](12-main-plugin.md) 为准——主插件是守卫执行者，本章保留指针与违反语义。（**守卫** = 运行时警察：预算超标就裁剪、字节不符就拒绝、补丁不规范就拦截、绕过回退链就禁入。）
违反 → `guard/violation {guard, module, detail}` + `violationRate` 度量（docs/07）。

## 5. 审查清单（模块合并前逐项确认）

- [ ] 信号取自会话日志确定性事件；
- [ ] 可查表/可匹配/可分支部分全部 L0 化；
- [ ] LLM 产物：版本化落盘 → 同输入同输出 → 有预算上限；
- [ ] 检索失败有显式降级路径；
- [ ] 步数最小自证附于模块注释；
- [ ] 工具结果自包含（无解引用/跨距离依赖）。

## 6. 合规自证模板（模块注释）

> 每个模块在注释里按这个模板自证合规：它属于哪个平面、回退链走几步、审查清单过没过、用的哪条度量。这正是"宁严勿松"的落点。

```text
模块: 示例
平面: L0（事件观测）+ L1（差分标注，小模型 ≤400 token）
回退链步数: 2（代码分支）→ 4（本地 embedding）→ 5（小模型标注）
审查清单: 全部确认（附日期）
度量: roundsSaved / costPerTask（docs/07 字段）
```

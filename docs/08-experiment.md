# 08 · 对照试验协议（A/B 实验设计）

> 判定"每件机制值多少钱"。方法：**消融阶梯 + 配对复现 + 盲评门控 + 预注册阈值**。
> 规则：只信配对差值（Δ = 臂 − 基线），禁止单次运行结论；先定假设再开跑。
> 实验框架与臂表的执行形态 = `experiments/evalground/`（EXPERIMENT.md 为其方法学单一事实源；
> 2026-09-06 起**封存**，解封条件见其 SEALED.md——对照实验随机制落地重建实验面后组织）。

## 0. 它解决什么问题（人话版）

加了一堆省 token 的机制，立刻要回答：**到底哪件真省钱、值多少钱？** 最容易自欺的是——
拿一个跑得好的例子当全局结论，或模型碰巧发挥好就归功机制。所以纪律先行：**先定标准、
再开跑，只信配对差值，禁止单次运行下结论**。做法是消融阶梯（一件一件开/关）+ 配对复现
（同一任务开关两态各跑一遍，差值抵消环境漂移）+ 盲评门控（裁判看不见臂标签）+ 预注册
（开跑前写死"达到什么才算赢"，跑完不许改）。代价是一次性跑批成本——这笔钱是"买结论"的钱。

## 1. 实验臂（消融阶梯）

| 臂 | 配置 | 目标 |
|---|---|---|
| A 基线 | 裸 DSH（默认压缩，无插件） | 基准 |
| B | 只开优化判别器（自动断面 + 星标） | 判别/断面单件收益 |
| C | 只开剪切层 | 微削单件收益 |
| D | 只开压缩器（边界 + 压力） | 折叠单件收益 |
| E | 全开 | 组合收益 |
| F* | 全开 − 判别器 | 判别器边际贡献（边界信号失效时压力层兜底的读数） |
| G* | 全开 − 剪切层 | 剪切边际贡献 |
| H* | 全开 − 压缩器 | 压缩边际贡献 |

（F–H 为 leave-one-out，回答"少了它差多少"——优先于 B/C/D 读数。）

**域内消融**（单变量；执行形态 = 解封重建后的实验面，见 `experiments/evalground/SEALED.md`）：

- 判别器：窗口式 vs 卷宗式 vs 卷宗+历史判定（锚定偏置消融）vs 批量判定；
  判定维度 = 边界 F1、侧问判定准确率、每任务判别成本、延迟。
- 压缩器：保留策略（近因门 vs 闭合即全压 vs 材料基准热尾）、产物结构（类型化信息块）——
  四旋钮方法论见 EXPERIMENT.md。
- 剪切：T-note 开/关、机械摘句 vs 裸 stub、run 冲刷阈值。
- 断面：门控阈值、对表层强度（tableHitRate 曲线）。

## 2. 任务集（分层，按工作负载形状）

| 层 | 场景 | 任务数 | 假设（H） |
|---|---|---|---|
| L1 长多轮（10+ 轮） | 跨天项目任务 | 3 | 剪切 + 压缩在腐蚀区降轮次与复利 |
| L2 文件密集 | 改 bug、重构 | 3 | 路径固定化砍掉查找轮（explorationAvoided） |
| L3 高纠正 | 风格/方向反复修改 | 3 | 星标断面整理意图，降返工 |
| L4 重复类型 | 同类任务 ×5 | 3 | 固定化路线复用 + 缓存命中率上升 |
| L5 短一次性（负对照） | 问一句就走 | 3 | 门控零增益、零损伤 |

- 固定同一仓库快照、同一工作区；任务 prompt 全部落盘；
- 每任务附验收标准（文件改动断言、测试通过、纠正次数）。

## 3. 判定指标（先过门，再比钱）

- **质量门**：完成率（验收断言）+ 盲评（固定 judge + 固定 rubric，不见臂标签）+ 人工抽样；
- **主指标**：`costPerSuccessfulTask`（[07 §3](07-metrics.md) 恒等式）；
- **归因诊断（不入判定）**：cacheReadTokens / extraSearchCalls / hotTailSource 等中间量，
  只解释"为什么"，不下"更优"结论。

## 4. 公平性控制（最易翻车处）

1. 同模型、同 provider、同 reasoning effort、同 temperature——effort 是最大混杂变量；
2. **配对**：同一任务所有臂各跑一遍，跑序随机化；
3. 复现 ≥3 遍，均值 ± 置信区间；
4. 交错 + 基线定期重跑（模型漂移由配对差值自然抵消）；
5. **冷/热缓存分开报**，绝不混合；
6. **换模型 = 换缓存体制 = 整批重跑并标注**（[06 §1](06-cache.md) 体制命题）——
   新旧批次数字不混用、不混批。

## 5. 统计与判定

- 配对 Δ = 臂 − 基线；Wilcoxon 符号秩 + bootstrap 95% CI；报告效应量；
- **预注册示例**：
  - H(L2, 断面)：explorationAvoided ≥30% 且质量不降 → 路径固定化保留；
  - H(L1, 剪切)：cutMisfireDetected = 0 且 costPerSuccessfulTask 降 ≥20% → 默认开；
  - H(L4, 全开)：缓存命中率不降且复利量降 ≥40% → 组合默认形态；
  - H(L5)：轮次/成本无显著变化（p>0.05）→ 门控无损伤。
- 阈值调参用验证集，最终判定用测试集。

## 6. 运营流程

```text
跑批（每臂×任务 = 全新会话；顺序执行）
  → 收会话日志 → 回放器算指标（07 §5）
  → 质量门（验收 + 盲评）→ 配对统计 → 报表（07 §6）→ 快照入档
```

## 7. 防自欺清单（跑实验前确认）

- [ ] 便宜但 40% 失败的臂不算赢（质量门先行）；
- [ ] judge 与 rubric 跨臂一致且盲；
- [ ] 无中途调参（预注册 + 验证/测试分离）；
- [ ] 冷/热、真实价/固定价分开报告；
- [ ] 断裂重价入账（最易漏记的隐性成本）。

## §1 背景：为什么另起新设计

R1–R4 把"机械可确定"的上下文管理做完了。剩下的最大一块是**语义层**——判断"这条工具结果是不是只需要一个结论"。

| 证据 | 数值 | 出处 |
|---|---|---|
| 机械档实测命中 | T-note **0** / T-loop 12 / T0 **0** / T0-R **0** | `ledger-history.md` §38/§39 |
| 本设计期回放（44 会话 / 2,045 条 ≥2KB 结果） | 机械可判"已吸收"仅 **3/1,706**（复述覆盖率 ≥80%） | 本设计期实测 |
| 可安全剪的块 | **421 条（20.6%）** → 省 **7,920 万 token** | 同上 |

| 结论：机械层无法识别"用完没有"；语义判断只能由**消费该结果的主模型**做 | — | `docs/03 §2.1` |

## §2 硬规则（不可违反）

1. **时机闸门**：只允许**写时剪**（内容尚未入账）或**尾部块剪**（消费后立刻）。
   任何更早位置的改写一律禁止——断裂成本 = 变更点之后全部体积 × 全价（`docs/06 §2`）。
2. **内容闸门（永不剪）**：项目代码事实（文件内容）· 外部事实（`web_fetch`/`web_search`）·
   改史（`write`/`edit`/编辑器写操作）· 副作用命令 · 认不出的。
3. **深度闸门**：尾部块剪后保留物 ≤ 原块 **1/10**（回本 ≈ 10 轮 @缓存价 1/100）。
4. **事实保真**：结论必须**逐字**含后续会用到的路径 / 数值 / 引号内文字 / 约束词；缺一 → 不剪。
5. **配对与失败方向**：整对剪（调用 + 结果）；无标记 / 解析失败 / 超时 / 护栏不过 → **保留原文**。
6. **判断主体**：语义判断只能由**消费该结果的主模型**做（旁观者无意图，`docs/03 §2.1` 已否决辅助摘要器）。
7. **带外原则**：插件内部标志不进模型视野；进模型视野的只有结论本身。

## §4 施工纪律（沿用 R1–R4）

- 每单验收第一行 = `npm run gate`（typecheck + typecheck:client + test + assert）+ `npm run typecheck:tests`。
- 尺寸预算：**M** = 2–4 文件 / ≤400 净行；**S** = 1 文件 / ≤150 净行；超预算必须在工单申报。
- 每个模块注释按 `docs/05 §6` 合规自证模板（平面 / 回退链步数 / 审查清单 / 度量）。
- 改动前后必须留账本快照（`docs/ledger-history.md` **只增不改**）。
- 结构断言随单追加（`scripts/assert-structure.mjs`）+ 更新零位快照。
- 新资产先登记（`docs/11 §7`）再写码。

## §5 与旧设计的关系

**保留**：剪切四档时机（写时 / 消费后 / 覆盖后 / 边界）· T-note 协商语义 · 配对纪律 ·
失败默认保留 · 带外原则 · 缓存断裂成本公式。

**修订**：
1. **T-entry 准入收窄**：从"所有 cmd"改为"结论型命令"——**代码事实移出**（见 §2 内容闸门）。
2. **T0 加尾部邻近守卫**：现状 `readsByPath` 无邻近约束，可能回溯剪掉很久以前的读取（违反 §2.1）。
3. **结论契约升级**：由"一句话"升级为"结论 + 关键事实逐字 + 重取句柄"。
4. **剪除范围扩大**：从"剪结果"扩大到"剪上一轮调用 + 结果 + 思考"（实测思考占工具调用轮 token 的 94.5%）。

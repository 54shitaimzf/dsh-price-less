## 3. 关键决策

1. **purpose 不修 harness**：`GenerateOptions.purpose` 的 interface 属性不能声明合并
   宽化（TS2717），且 DeepSeek adapter 对未知 purpose 无 wire 差异——采用插件侧
   `Omit` + 单点 cast（docs/12 §1 C2），P5 消费本地宽化类型。
2. **T-entry 改挂 `tools/post-execute`**：`tools/execute` 返回值会被
   `normalizeDispatchResult` 按 `value` 重新 render content，content-only 修改丢失；
   `tools/post-execute` accept `content` 覆盖才是落账前整形缝。机制语义不变。
3. **client 冒烟只测注册/卸载**：真浏览器渲染仍属用户核验；本单锁定可机械验证的
   slots/settingsScope/remote/connection 接线。

## 1. 目标

把 named logger `context-economy` 的诊断消息经 cordis 公开导出面追加为 JSONL 文件
`<插件根>/logs/context-economy.log`（2 MiB 封顶滚动保留 1 份）——agent 无需 console、无需
harness 改动，直接 Read/grep 该文件即可自审插件行为。零新配置字段、零模型视野变化。

### 2.4 决策点记录（执行者不再自行裁量）

1. **日志位置 = 插件根 `logs/`**（用户定调）；解析序 `opts.dir` > 环境变量 `CE_DIAG_DIR` >
   `<插件根>/logs`。插件根 = 本模块文件上两级（`lib/platform|src/platform → 根`，tsc rootDir=src
   两形态同深度）。`CE_DIAG_DIR` 供测试重定向与环境兜底，非配置面（零新配置字段）。
2. **不 import cordis 运行时**（src 现状：全部 cordis import 为 type-only，本单维持）：消息
   格式化本地最小复刻（`%s%d%i%f%o%O` 占位、Error 首参取 stack、尾参空格拼接、对象 JSON 化；
   `%%` 不解包——ceLogger 不用）。类型面仍 type-only import `Context/Exporter/Message`。
3. **DEBUG 全档捕获**：导出器声明 `levels: { default: 3 }`（门在 cordis 读取，:155）；体积由
   2 MiB 封顶滚动兜底。
4. **失败语义（失败方向朝安全侧）**：能力缺失（无 `ctx.effect` / `logger.exporter`，测试替身
   形态）→ 静默返回 undefined（apply-smoke 零改动的根据）；能力在但建目录/追加失败 →
   `console.error` **单次**告警后 sink 永久停用（可见、不成灾）；rotation stat 失败 = 文件
   尚不存在，静默。永不抛出。
5. **注销归属**：`exporter()` 内建 disposer 挂在 LoggerService 的根 fiber（:233 用
   `this.ctx.effect`）——插件卸载不会自动摘除。挂载经**本插件** `ctx.effect` 承接其返回的
   disposer（卸载即净，11 §1 入口铁律）。
6. **与 docs/12 可删除单元互斥**：本文件零共享符号、零 import（logger.ts/ignorable-channel.ts
   反向亦然）；docs/12 §2 补一句边界登记——两单元可独立整删。
7. **JSONL 行 schema 冻结（4 字段）**：`{ts(ISO), level(message.type 字符串), name, msg}`。
   日志非模型可见、非账本（07 回放不读它），字节稳定铁律不适用。

## 6. 禁区与注意（总纲 §2 全文继承，此处只列本单特有）

1. **不进模型视野**：日志文件绝不参与任何 prompt/消息装配；它是盘上带外产物（01 §4）。
2. **诊断 ≠ 事实轨**：本文件不写会话 JSONL、不 import ignorable 单元任何符号（D3 天然不涉；
   违者即破 docs/12 边界）。
3. **失败不成灾**：唯一允许的 stdout 面 = 单次 `console.error`（sink 自身失效时 logger 可能
   已不可用，故走 console）；其余一切失败静默停用。
4. **停工上报触发器**：① `exporter()` 返回值非函数（注销面变化）；② statSync/appendFileSync
   在正常目录上持续失败；③ 行数预算超限无法精简；④ 任何未覆盖决策点。

# 02 · 优化判别器（核心一）

> 域定义：**优化判别器 = 一个理解核、两个断面**——手动断面（星标通道：一次全量理解，
> 产优化后 prompt + 判别回填 + task 边界 + 剪切清单）与自动断面（逐消息流式判定，
> 校准后降格为对表判别）。它同时是 task 生命周期（[01 §3.5](01-architecture.md) 意图轴）
> 的发现者与执行路线确定化的生产者。
> 状态：设计 · 未实现（搭建序见 [11](11-structure.md) R2）。

## 0. 它解决什么问题（人话版）

一个会话里用户会连着干好几件事，但从来不说"这件干完了、开始下一件"——边界只能从消息的**语义**里猜（机械信号猜不出"换意图了"，实测翻转绝大多数是纯语义的）。猜错边界，压缩、归档全跟着错位；不猜，历史就无限膨胀。同时，用户的原始指令往往写得随性：意图、约束、验收标准、操作路径散落在几十条消息里，模型每一轮都要重新理解一遍，还要靠反复 grep/glob 试错去找"这件事到底怎么做"。

优化判别器把这两件事合成**一个理解核**：读 task 内的用户消息，既判边界（判别器的老本行），又把散落的意图/约束/验收/路径**整理成一份确定化的执行包**（优化器的本行）。手动断面（用户点星标）产出全套；自动断面逐消息值守。模型只碰语义核心——分类、选择、压缩；时机、范围、校验、记账全部机械（§4 审计表）。

## 1. 一个理解核、两个断面

| | 自动断面（流式） | 手动断面（星标） |
|---|---|---|
| 触发 | 每条用户消息（输入面过滤后） | 用户点星标 / `/optimize-prompt`，按需 |
| 成本预算 | 极小：T0→对表链先走，歧义才上 LLM（P14c 实测机械层仅省 7.9%） | 一次全量 LLM 断面（产品价值正当化） |
| 输出 | 裁决位：边界判定 + 三分类 | 完整产品 + 全套裁决位（回填） |
| 失败语义 | fail-lazy（判 continue，异常不外溢） | 默认不动（不回填、不替换、不剪） |

**信息包含关系**：判别器的输出 ⊂ 优化器的理解断面——星标读全量消息做意图整理时，三分类与边界裁决顺手就出来（零额外调用）。但两个断面**执行上必须分立**：自动断面绝不能字面实现成"跑优化器丢产品留裁决"（每消息付产品生成成本，违宪）；它有自己的廉价链。

**统一律（宪法级）**：两个断面共享同一**卷宗**（§2）与同一套三分类标尺；星标回填 = 对已覆盖区间的**终审**（版本 +1，同区间永不重判）；此后的自动断面降格为**对表判别**——不再开放式地问"这是什么意图"，而是封闭式地问"这条消息是否偏离已固化的意图结构"（文件签名重叠 + 关键词对表，机械为主，出表才上 LLM）。固化的是参照系，不是判别功能本身。

## 2. 输入栈（两断面共用）

```
① 稳定前缀（项目级，版本化，字节稳定）
     = 技能目录（机械枚举，零 LLM） + 项目最终目标（项目帧 vN）
② 卷宗 = task 内全量用户消息（append-only 累积）
③ prompt（压最尾 = 断面时刻待优化的当前指令；自动断面 = 当前消息）
```

- **技能目录**：枚举 DSH skill 系统已安装技能（root 扫描 `SKILL.md`，取 name / description /
  whenToUse；目录热更新）。技能 = 固定操作路径的仓库，是路径确定化（§5）的引用来源。
  清单是查表产物，**永远不靠模型回忆**。
- **项目帧**：项目最终目标（一句话到一段话）+ 方面分解（项目有哪几个方面——task 意图归属的
  判别参照系，[01 §3.5](01-architecture.md)）。采集走 init 过程：首次会话一次 LLM 整理 +
  **用户确认**（相信用户决策，宪法条文八），落项目帧 v1；修订经星标/设置，版本 +1。
- **卷宗纪律**（三轴）：**原文逐条累积**（不摘要、不转写——用户消息是稀疏高信号信道，
  整卷通常 ~10K token 量级）；**不积累历史判定**（不给提示词"可推翻前判"的纪律负担，
  锚定偏置从结构上消除）；**task 边界清空**（新 task 新卷宗，作用域天然有界、新鲜、无偏）。
- **输入面过滤**（自动断面，只有这些消息进判别）：`user/message` append + `source.kind==='user'`
  + 主会话（子代理会话不判）+ 非伪 user（approval 等系统消息不判）+ 文本非空 + u≥1
  （首条由段状态机隐式开段，不判）。
- **不进输入栈的东西**：工具结果正文、assistant 回复正文、其他 task 的卷宗——断面燃料
  只有用户消息；证据进统计摘要，正文不进。

**缓存账**：①跨 task 稳定（技能装卸 / 项目帧修订才 bump）；②task 内只追加；③每次变——
断面调用本身按"模板在前、实例在后"渲染，前缀天然对齐（[06](06-cache.md)）。

## 3. 自动断面（流式判别 + 对表）

**决策链**（每条消息按序走，命中即返回；顺序 = 成本顺序，前三级全免费）：

| 步 | 通道 | 判定 |
|---|---|---|
| 1 | T0 显式指令 | `/task <描述>`（open）/ `/task close`（close）→ 边界事实，判别器只记账 |
| 2 | L1 精确键缓存 | 同会话 + 同 seq + 同配置 + 同文本 → **重复投递护栏**（跨消息永不命中，不省调用） |
| 3 | LLM 主路径 | 判据模板（版本化落盘，datasets 同源断言防漂移）渲染卷宗 + 当前消息 → 判定 |
| 4 | fail-lazy 兜底 | 任何错误/超时 → 判 continue（宁可漏切，不打断会话；异常永不外溢） |

- **三分类搭车**（第 4 步同一调用加输出维度，边际成本 ≈ 输出 token）：每条消息判
  **动作 / 纯理解提问 / 验证提问**——判别器与剪切层（[03 §3](03-shear.md)）共享的标尺。
- **对表层 = 影子记账（P14c）**：星标回填产生权威意图结构后，对表层**只算不拦**——命中照常走
  第 3 步 LLM，只把"机械本会怎么判"记进账本（`tableShadowHitCount` / `tableShadowMissedBoundaryCount`）。
  命中打分：文件签名 2 分、具体关键词（≥4 字符或标识符形态）2 分、泛关键词 1 分。
  **理由**：机械误判"延续"是无声错误（边界漏切且无复核）；实测若启用短路，354 条真实记录里
  会放行 28 条、其中 1 条是边界——每千条省 1.8 美分却平均漏 2.8 个边界，不划算。
  唯一允许不调模型就下结论的是 T0（用户显式宣告）与 L1（重放同一条消息的既有裁决）。
- **段状态机**（事实归宿，纯 fold、从会话日志重建）：T0 open/close 与 LLM verdict
  （new-task → 段内切分：旧段闭合于前一条表面事件、新段以判定消息为段头）驱动段切换；
  `discriminator.auto=false` 时判别器不挂载（零成本）；`true` 时发 `judge-verdict` 接入投影，
  段状态机只在 T0 与有效 verdict 驱动下切分；T0 天然优先（verdict 落在段起 seq 时 no-op）。
  （观察模式已取消，2026-09：实验结论已固化进设计，不再设 observe 门控。）
- **发送参数自适应**：调 LLM 前取运行时能力许可（`reasoning.efforts`）与版本化实测能力表
  交集，交集外一律不发送（= 默认档）——供应商包更新不会让参数失效。

**模式与配置**：`discriminator.auto` 为 boolean（默认 **false**：不挂载、零成本；true：发
verdict 接入投影）。星标通道**常在**，不受此开关门控。（观察模式已取消，2026-09。）

## 4. 手动断面（星标通道）

**触发**：client conversation.view 星标按钮 / `/optimize-prompt`（同一管线，一入口两形态，
[10 §1](10-wiring.md)）。上下文 = §2 输入栈全量。

**门控（P14c 修订）**：**唯一门控 = 本次提示词极短**（去标点空白后 < 4 字符）→ 零调用短路，
不调模型、不发事实、不写盘。历史消息少**不再**跳过产品层——task 早期正是优化收益最大的时刻；
无历史素材时产品仍产出，弹层提示"仅基于当前提示词与项目帧"。

**时机经济学**：优化后 prompt 的固定化内容从下一轮起每轮复用；产出越早、摊销期越长。
**task 早期、意图已清晰时点击最优**——晚点击（临近闭合）收益被剩余轮次摊薄，
剪除搭车（§5）的断裂尾巴也更贵（[03 §1](03-shear.md) 断裂成本公式）。

**一次断面、五个出口**（产出与消费者）：

| 出口 | 形态 | 消费者 |
|---|---|---|
| A 优化后 prompt | 自由文本，预览 → 用户确认 → **直接发送**（P14d） | 用户 + 主模型（可见层） |
| B 判别回填 | 卷宗版本 +1（落状态不落历史字节） | 自动断面（对表参照系）、边界档案归档 |
| C task 边界裁决 | 离散决策（意图切换点），**只判断不执行** | 边界压缩（[04 §3](04-compactor.md)）、归档 |
| D 剪切清单 | 行式记录，机械执行（surfaceOp） | 剪切层（[03](03-shear.md)） |
| E 度量事件 | log-only | [07](07-metrics.md) 账本 |

- **A 优化后 prompt**（P14d 修订）：**关键事实保真 + 重写为公认的优秀结构**——关键事实（路径、
  版本/数值、引号内文本、约束与合规词句、KEEP 的候选段）逐字保真；其余文字**大胆重写**（删冗、
  并重复、口语改精确指令、重排）；结构按"目标 → 交付物与验收 → 约束与禁止 → 执行路径"自然成文，
  **禁止分节标题与标签**（"关键路径锚定：""探索豁免声明"这类字样不许出现），**禁止元注释与自我
  说明**（"原样保留用户提示词""以下为优化后提示词"）——这些内容要融入行文，不是分块罗列。
  产品是**可见可改**的提示词，不是隐藏指令；用户编辑即终稿，确认即发送。
- **B 判别回填**：对卷宗全部消息的三分类终审 + task 意图画像（目标/范围/涉及方面）。
  manual 模式下它是唯一裁决源；auto 模式下是权威升级，与既有裁决冲突以回填为准、
  `verdictBackfill.conflicts` 记审计。落卷宗（KV），零历史字节变化、零缓存代价。
- **C task 边界**：回填发现的意图切换点输出为建议；**星标不隐式执行边界动作**——闭合牵动
  边界压缩与归档（大事务），须 T0 显式（`/task close`）或自动断面判定；发现实质切换时
  提示用户显式闭合。
- **D 剪切清单**：仅当卷宗含理解/验证 run 时产出（[03 §3](03-shear.md)）——run 是连续的
  追问链/验证链，整段为单位，不是逐对；清单行 = 坐标 + 一句结论。

**机械化审计表**（什么留给模型、什么不给——宪法平面分级的执行面）：

| 事项 | 机械 / 模型 | 依据 |
|---|---|---|
| 门控（P14c：极短提示词） | 纯机械 | 本次提示词去噪后字符数阈值（host/client 同口径） |
| 关键事实保真检查 | 纯机械 | 必保事实（路径/引号/数值）∪ 模型 KEEP 的包含性检查 |
| 产品元注释剥离 | 纯机械 | 开头连续元注释行判据（窄口径；剥空回退原文） |
| 技能/命令引用存在性 | 纯机械 | 目录表查表（引用守卫，[05 §4](05-constitution.md)） |
| 剪切时机与范围 | 纯机械 | 分类给定后扫描推导（动作到达即剪） |
| 三分类 | 大部分机械 | T0 与对表先行；歧义余渣才语义；断面内反正免费 |
| 边界检测（新消息） | 校准后大部分机械 | 文件签名 + 关键词对表，出表才 LLM |
| 短 run 结论句 | 机械摘句 | ≤1–2 对时首句规则摘录 |
| 长 run 结论句 | LLM | 多轮收敛的语义压缩 |
| 意图结构 | LLM | 语义核心本核 |
| 约束/验收的选择 | LLM 选择 + 机械拷贝 | 候选段事实级预抽（路径/引号/数值必保），挑哪些约束重要是语义 |
| 技能/路径相关性选择 | LLM | whenToUse 语义匹配 |
| prompt 组装 | LLM 生成 + 机械校验 | 生成语义、四道闸校验机械 |

断面内 LLM 只剩四件语义事：**意图结构、约束/验收选择、技能/路径选择、长 run 结论句**。

**双通道输出契约（基本不打回）**：

- **产品通道 = 自由文本**：任何文本都是合法 prompt，结构上无从打回；最终把关 = 预览 +
  用户确认（确认即发送；人在环吸收产出质量问题）。
- **裁决通道 = 行式记录，行级失败隔离**：每行一条独立决策（`BOUNDARY 12` /
  `SHEAR 3..7 已吸收：…` / `SKILL build-fix`），逐行解析，坏行丢弃**那一行**（该决策默认
  保留——失败方向永远朝安全侧），好行照常执行；无全局拒绝、无重试、异常成本 = 零额外调用。
- **选坐标不造坐标**：行号、范围、技能名只允许从输入枚举（消息坐标表、技能目录）里**选**，
  解析 = 查表校验——模型不发明标识符，就没有非法标识符。
- **机械钳制兜底**：结论句长度上限（超长截断安全）、决策行数上限、候选 span 机械预抽注入
  （模型只勾选）。
- **协议确定性**：单次调用、temperature 0、宽松 completion 预算、断面内**无工具调用**
  （纯文本进出——断面读的是预先装配好的输入栈，不需要边跑边查）。

**判别生命周期总述**：向过去（已覆盖区间）——回填即终审，同区间永不重判；向未来（新消息）——
判别继续但对表化。星标可重复点击：每次都对"上次回填之后"的增量卷宗做新一轮断面
（卷宗版本链，[09 §2](09-state.md)）。

## 5. 执行路线确定化（断面产出的长效面）

优化后 prompt 的固定化内容在 task 内持续生效，是"多做、只在必要时刻探索"理念的生产端：

- **钉路径**：复杂操作固化为技能/命令显式引用（引用守卫校验存在性——幻觉技能名机械拦截）；
- **钉决策点、软化顺序**：条件化步骤序列，只引用本会话当前装配的工具集；
- **探索降级为例外**：已钉死的路线不试错；探索仅在固定路线不覆盖时启动，其成果回填固定化
  （下次不再探索）——把"惰性求值"反转为"提前求值 + 复用"。

度量化：`explorationAvoided` = 星标后探索类工具调用（glob/grep/read 试错）相对基线速率的
配对下降（[07](07-metrics.md)）。

## 6. 事件与度量

- 事件（log-only）：`judge-recorded` / `judge-error` / `judge-verdict`（active）/
  `task-boundary`（段状态机边界事实）/ `optimize-run`（星标断面全账：输入栈体积、产出、
  回填、剪切清单规模）。
- 度量（定义见 [07](07-metrics.md)）：判别侧 `judgeCount` / `judgeErrorRate` /
  `judgeCacheHitRate` / `judgeLatencyMs` / `l0CaptureRate` / `tableHitRate`；
  断面侧 `optimizePromptTokens{in,out}` / `verdictBackfill{count,conflicts}` /
  `explorationAvoided`；投影侧 `segmentsPerSession` / `taskSwitchRate`。

## 7. 验收标准（协议级断言）

- [ ] `auto=false` 零行为影响（判别器不挂载）；机械层只做查表（P14c 已删 L0 词表）；
- [ ] active verdict → 段状态机切分语义正确（新段锚 = 判定原文；过期/不可定位 no-op）；
- [ ] 星标断面：关键事实保真检查（必保事实 ∪ KEEP 的包含性断言）+ 元注释剥离 + 引用守卫（未知技能名拒绝）；
- [ ] 裁决通道行级容错：注入坏行仅该行默认保留，产品与好行不受连坐（注入测试）；
- [ ] 回填后自动断面走对表（tableHitRate 上升、judgeCount 下降，经 07 账本真机观测）；
- [ ] 一切异常 fail-lazy / 默认不动（错误链入账，不外溢会话流）；
- [ ] 判据模板版本化 + datasets 同源断言；卷宗回放确定（同日志重放同卷宗同版本）。

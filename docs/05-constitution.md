# 05 · 宪法与守卫

> 域定义：**给全部机制提供判定原则与审查口径**——五理念（总纲）、八条文（判定原则）、
> 回退链（成本阶梯）、守卫表（运行时警察）。任何模块合并前按本文自证。
> 状态：设计 · 未实现（守卫接线见 [11 §3](11-structure.md)）。

## 0. 它解决什么问题（人话版）

这套件的机制很多，最怕各写各的：该用规则算出来的去请模型、能查表的版本号重算一遍、
失败没有兜底直接崩、趁用户不注意把它的原话改了。这篇就是全套机制的"裁判 + 尺子"：
先立五条**理念**（为什么这么设计），再立八条**条文**（每题一句话，判断该不该让模型碰 /
该不该动刀），一条**回退链**（从最便宜到最贵，逐级尝试不跳层），一张**守卫表**
（运行时警察：越界就拦）。任何模块要合进来，先按审查清单自证"够便宜、够确定、可复现"。

## 1. 五理念（总纲）

1. **缓存复用**：缓存体制决定最优上下文策略——本套件面向高命中率、无写溢价、无服务端
   缓存操作的体制优化，字节稳定与追加式是一切机制的地基（正典见 [06](06-cache.md)）。
2. **软件架构经验提取**：从易变对话中提取稳定的项目结构事实（架构布局、构建/测试路径、
   声明表结构、项目最终目标），在稳定点固化、跨 task 复用（落点：项目帧、路径固定化、
   [04 §6](04-compactor.md) 边界档案）。
3. **无关内容剪枝**：已吸收的问答、已被超越的读、已交付结论的过程——在正确时机整块移除，
   只留依据（落位律 §2.8，剪切层 [03](03-shear.md)）。
4. **执行路线确定化**：能提前钉死的绝不临时搜索——复杂操作固化为技能/命令显式引用，
   坐标直接寻址，探索降级为例外（[02 §5](02-discriminator.md)）。
5. **多做，只在必要时刻探索**：愿意多做前置功（提取、固化、整理、版本化——一次性成本），
   换变量成本（探索试错）消失；探索仅在固定路线不覆盖时启动，成果回填固定化。
   **多做的另一面是相信用户决策**——用户显式宣言、确认与编辑是最高信号，系统不二次揣度。

## 2. 宪法条文（判定原则）

1. **确定优先**：可观测的用日志事件，可计算的用规则，可查表的用版本号；
2. **模型最小断面**：进入模型的每个 token 满足两个条件——非可确定计算；缺失会导致猜错；
3. **字节可复现**：同输入 → 同输出；LLM 产物的复用先版本化落盘（同版本内容逐字节一致，
   缓存命中的物理基础）；
4. **成本可见**：任何进入请求的 token 都有预算与度量（[07](07-metrics.md)）；
5. **降级显式**：确定性检索失败走明确降级路径（off 档、机械等价、占位 + 用户可控指令）；
6. **自包含有效性**：模型可见的工具结果必须是"内容即所得"的实际文本——需要解引用/重建/
   跨距离关联的机制无效；
7. **度量先行**：改动必须可被 [07](07-metrics.md) 观测——先立度量后写代码；
8. **相信用户决策**：用户显式指令一票算数（Tier-0 压倒自动判定）；星标回填即终审；
   预览确认即生效；**用户编辑即终稿**（不建学习存储去揣度编辑意图）；
   剪除不成不动刀（判据不成立/解析失败/超时一律默认保留）——失败方向永远朝用户数据安全侧。

## 3. 回退链（逐级尝试，成本递增）

```
1. 用户可控指令（用户显式规则直接采用——Tier-0）
2. 代码分支（gating / 门控 / 阈值判定）
3. 机械字符匹配（关键词、模式、正则、哈希、词表）
4. 本地 embedding（相似度检索，离线；端口空壳，见 §5）
5. 极小本地模型（差分标注、机械摘录辅助；输出可版本化、预算受限）
6. 被调用的大模型（最小断面：判别 / 压缩 / 结论提取）
```

各域共享、**绝不跳层**；每个模块自证"步数最小"：第 2 步可解的不到第 5 步。
对表判别（[02 §3](02-discriminator.md)）是第 2/3 级在判别场景的形态——校准后大部分
消息在链上第 3 级以内解决。

## 4. 守卫表（运行时警察）

装配期预检 + 运行期拦截；违反 → `guard/violation {guard, module, detail}`（log-only）
+ `violationRate` 度量。

| 守卫 | 检查 | 违反动作 |
|---|---|---|
| **引用守卫** | 优化产物中引用的技能/命令名必须在枚举目录中存在（查表） | 拒绝该引用（行级丢弃，产品其余部分存活） |
| **字节守卫** | 同版本卷宗/项目帧/档案/优化产物哈希一致 | 漂移即拒绝复用，回退上一版本 |
| **配对平衡守卫** | 任何剪除/压缩区间不拆散 tool_call/result 对 | 违例区间收缩到最近平衡边界 |
| **回退链守卫** | 模块自证步数最小（§6 模板） | 违宪禁入（装配期拦截） |
| **预算守卫** | 断面输入栈、结论句、热尾、检查点、档案区各守预算上限 | 超限机械裁剪/截断（截断安全，不 fail） |

## 5. embedding 端口（空壳留门）

`EmbeddingPort`（接口 + 余弦相似度）保留为回退链第 4 级的**零成本空壳**——不携带模型与
运行时；任何机制若接入 embedding 实现，仍遵循"机械优先、低置信窗口才触发"的降级矩阵
（失败回退机械等价：关键词 + Jaccard + symbol 查表）。

## 6. 审查清单与合规自证模板

模块合并前逐项确认：

- [ ] 信号取自会话日志确定性事件；
- [ ] 可查表/可匹配/可分支部分全部 L0 化（对照 [02 §4](02-discriminator.md) 审计表的形状）；
- [ ] LLM 产物：版本化落盘 → 同输入同输出 → 有预算上限；
- [ ] 检索失败有显式降级路径；失败方向朝"默认保留"；
- [ ] 步数最小自证附于模块注释；
- [ ] 工具结果自包含（无解引用/跨距离依赖）。

```text
模块: 示例
平面: L0（事件观测）+ L1（差分标注，小模型 ≤400 token）
回退链步数: 2（代码分支）→ 4（本地 embedding）→ 5（小模型标注）
审查清单: 全部确认（附日期）
度量: cutTokensSaved / costPerSuccessfulTask（07 字段）
```
